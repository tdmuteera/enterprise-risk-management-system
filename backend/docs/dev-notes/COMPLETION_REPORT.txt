MODEL: User
  Fields: id, username, email, full_name, hashed_password, role, 
          department_id, is_active, is_verified, created_at, updated_at,

  Roles: ADMIN, RISK_OFFICER, DEPARTMENT_HEAD, AUDITOR, VIEWER

MODEL: Department
  Fields: id, name, code, description, head_id, is_active, 
          created_at, updated_at

MODEL: Risk
  Fields: id, title, description, risk_category, department_id, owner_id,
          severity, status, likelihood_score, impact_score, overall_score,
          identified_date, due_date, review_date, evidence_files, tags,
          created_at, updated_at
  Enums: Severity (CRITICAL, HIGH, MEDIUM, LOW)
         Status (NEW, ACTIVE, MITIGATING, RESOLVED, ARCHIVED)

MODEL: RiskLink
  Fields: id, source_risk_id, target_risk_id, link_type, notes, created_at

MODEL: RiskHistory
  Fields: id, risk_id, changed_by_id, action, old_values, new_values, 
          notes, created_at

MODEL: Mitigation
  Fields: id, risk_id, title, description, owner_id, status,
          target_completion_date, actual_completion_date, budget_allocated,
          effectiveness_score, created_at, updated_at
  Enums: Status (PLANNED, IN_PROGRESS, COMPLETED, ON_HOLD, CANCELLED)

MODEL: Alert
  Fields: id, alert_type, risk_id, title, message, severity, status,
          assigned_to_id, acknowledged_by_id, acknowledged_at, due_date,
          created_at, updated_at
  Enums: Type (RISK_ESCALATION, MITIGATION_DUE, POLICY_VIOLATION, 
         AUDIT_ALERT, SYSTEM_ALERT)
         Status (PENDING, ACKNOWLEDGED, RESOLVED, DISMISSED)

================================================================================
                      GETTING STARTED (Quick Start)
================================================================================

1. SETUP ENVIRONMENT (30 seconds)
   python -m venv venv
   venv\Scripts\activate  (Windows) or source venv/bin/activate (Mac/Linux)
   pip install -r requirements.txt

2. VALIDATE SETUP
   python validate_setup.py

3. START DEVELOPMENT SERVER
   uvicorn main:app --reload

4. ACCESS API
   Open browser: http://localhost:8000
   Swagger Docs: http://localhost:8000/docs
   ReDoc Docs: http://localhost:8000/redoc
   Health Check: http://localhost:8000/health

5. READ DOCUMENTATION
   Start: 00_START_HERE.md
   Development: DEVELOPMENT.md
   API Reference: README.md
