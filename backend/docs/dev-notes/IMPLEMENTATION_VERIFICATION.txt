SCORING FORMULAS SUMMARY
════════════════════════════════════════════════════════════════════════════

Raw Score:
  Score = Likelihood × Impact × Velocity × Detectability
  Range: 1.0 to 625.0

Normalised Score:
  Normalised = round(Raw / 6.25, 1)
  Range: 0.2 to 100.0

Colour Band:
  IF Score >= 65:   Critical (#D32F2F, red)
  ELSE IF >= 40:    High (#F57C00, orange)
  ELSE IF >= 20:    Medium (#FBC02D, amber)
  ELSE:             Low (#388E3C, green)

Institutional Risk Index:
  IRI = Σ(linked_scores) × avg(weights) × sqrt(unique_depts)
  Purpose: Measure institutional impact of risk cluster
