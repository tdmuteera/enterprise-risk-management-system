SCORING FORMULAS
════════════════════════════════════════════════════════════════════════════

RISK SCORE (Raw)
  Formula:  Likelihood × Impact × Velocity × Detectability
  Range:    1.0 (minimum) → 625.0 (maximum)
  Factors:  All integers 1-5
  Example:  5 × 5 × 5 × 5 = 625.0

NORMALISED SCORE (Display)
  Formula:  round(risk_score / 6.25, 1)
  Range:    0.2 → 100.0
  Example:  625 / 6.25 = 100.0
  Example:  1 / 6.25 = 0.16 → 0.2

COLOUR BANDS (From Normalised Score)
  Critical: 65-100   → #D32F2F (red)      [bg-red-600]
  High:     40-64    → #F57C00 (orange)   [bg-orange-600]
  Medium:   20-39    → #FBC02D (amber)    [bg-amber-400]
  Low:      0-19     → #388E3C (green)    [bg-green-600]

INSTITUTIONAL RISK INDEX (IRI)
  Formula:  Σ(linked_scores) × avg(weights) × sqrt(departments)
  Purpose:  Measure institutional impact of risk cluster
  Example:  (50+45+30) × 0.7 × 2 = 175.0
  sqrt():   Prevents linear explosion (1→1, 4→2, 9→3)

SUPPORT & TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

Q: Tests won't run with pytest?
A: Ensure pytest and pytest-asyncio installed:
   pip install pytest pytest-asyncio

Q: Scoring formulas different from spec?
A: Check that all factor ranges are 1-5:
   - Less: will produce lower scores
   - More: invalid (validation error)

Q: IRI always returns 0?
A: Likely no linked risks. Add links via RiskLink table.

Q: Colour band colors not displaying?
A: Verify frontend uses correct hex (#D32F2F) or Tailwind class

Q: APScheduler not running recompute_all_scores?
A: Check scheduler configuration and ensure job is registered
